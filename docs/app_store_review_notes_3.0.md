Harrier Central is the club app for Hash House Harriers - a worldwide social running group. Runs are organised by local clubs ("kennels"); members RSVP, check in on the day, follow the trail on a live map, and share photos and songs.

SIGNING IN - please use the account we have set up for you
The app does not use a username and password. To sign in:
  1. Launch the app and tap "Connect to Existing Account".
  2. Type this invite code:  APLECP
Sign-in completes straight away - there is no email confirmation step. This is
the same "Apple Test" account used for previous reviews; it already follows a
number of clubs, so the Runs list has content immediately.
(New users normally get a six-character invite code from their club, or create
an account from scratch. Sign in with Apple is also offered.)

WHAT TO LOOK AT IN 3.0
- Runs tab: upcoming and past runs. Open a run for Details, RSVP, Map, Stats, Chat and Photos.
- PackTrack (the headline feature): open a run, then "Live Run Tools". Tracking uses background location to draw the pack's route on a shared map, so please allow location and use Features > Location > City Run in the simulator, or walk a short distance on a device. The Map tab of any past run replays a recorded trail without needing location.
- Apple Watch: the companion mirrors a tracking session from the phone and sends trail marks back. It shows "Waiting for your phone..." until the phone starts tracking.
- Explore tab: a world map of runs, browsable without joining a kennel.
- Songs tab: the songbook; any RSVP'd member can share the current song to everyone's phone.

NOTES ON PERMISSIONS
- Location drives PackTrack. "Always" is what lets a run keep tracking with the screen off or the app in the background, so the rest of the pack sees the trail continue.
- Camera and Photos are used for run photos, which members can mark Private, Members-only or Public.
- Chat and photos are user-generated; kennel admins can delete content and photos are reviewed before they appear publicly.

This is the first App Store release since 2.1.2 (October 2025) and is a substantial rewrite: live tracking, chat, photo review, an interactive songbook, offline check-in and payments, and native iPad support.
